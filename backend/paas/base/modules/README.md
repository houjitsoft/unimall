# base 的插件管理模块

插件目录、授权、市场、制品、发布审核和升级的管理实现统一在本目录。它们是 Maven 库，装配进 `base` 服务运行（`base` 即插件中心服务），不承载 OA、ERP、MES 等领域实现。

| 模块 | 职责 |
|---|---|
| `plugin-center` | 插件目录、创建脚手架、安装状态编排、站点身份 |
| `plugin-registry` | 插件注册表同步（市场 ↔ 注册表 ↔ 架构清单一致性） |
| `plugin-market` | 插件市场：商品、订单、支付、结算、制品下载授权 |
| `plugin-license` | 授权与维护期：购买/沙箱口径、维护期策略 |
| `plugin-artifact` | 制品库：上传、签名、下载票据 |
| `plugin-publish` | 发布审核：开发者门禁、管理员闸门、审核流 |
| `plugin-update` | 安装/升级流水线：兼容性预检（框架版本/依赖/宿主匹配 3020）、8 步安装流水线 |

全链路验收脚本：`deploy/verify-plugin-chain.sh`（12 步：创建 → 上传 → 审核 → 上架 → 下单 → 支付 → 授权 → 换票下载 → 安装）。
