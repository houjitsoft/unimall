选择安装方式

推荐

Docker 默认安装

自动创建预定义的中间件与数据库容器（MySQL / Redis / Nacos / RocketMQ），全自动初始化、随机化口令。

  • 需要本机 Docker ≥ 24，安装期间占用约 8GB 内存
  • 数据库初始化约 10-40 分钟（670+ 张表）
  • 安装完成后展示各服务的访问信息

自定义安装（外部中间件）

使用你已有的数据库 / Redis / Nacos，仅部署应用服务（宿主机 host 网络直连）。

  • 填写各自的地址、端口、账号密码并测试连接
  • 数据库需可写（安装向导自动建库、建表、灌种子）
  • 应用服务直接占用宿主机端口（8391 等）
